# 🛠️ Essential Developer Tools & Utilities

---

## High-Performance CLI Tools
- **ripgrep (`rg`)**: Ultra-fast line-oriented regex search engine.
- **fd (`fd`)**: Intuitive, lightning-fast alternative to `find`.
- **fzf**: Interactive command-line fuzzy finder.
- **jq & yq**: Command-line JSON and YAML processors.
- **bat**: Cat clone with syntax highlighting and Git integration.
- **eza**: Modern, feature-rich replacement for `ls`.
- **zoxide**: Smarter `cd` command that learns your habits.

## Terminal Multiplexing & Environments
- **tmux**: Terminal multiplexer for persistent remote workflows.
- **Zellij**: Modern Rust-based terminal workspace with tabs and layouts.
- **WezTerm & Alacritty**: GPU-accelerated terminal emulators.

## Profiling & Debugging
- **Wireshark**: Network packet analyzer and protocol inspector.
- **GDB / LLDB**: GNU and LLVM debuggers.
- **Valgrind**: Memory leak detection and memory access profiler.
- **eBPF (BCC / bpftrace)**: Dynamic kernel tracing and performance analysis.
