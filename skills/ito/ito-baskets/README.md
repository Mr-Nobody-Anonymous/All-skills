# Itô Baskets

Part of the **ito** skill surface (`ito-*`).

Read-only Itô basket and prediction-market data workflows: browse the live
basket catalog, compare a basket against user-supplied research or a
watchlist, build a source-grounded market brief, or draft a non-executable
planning worksheet. It never advises, orders, trades, reserves, or executes.

See [SKILL.md](./SKILL.md) for detailed capability instructions, workflow, and
safety guidelines.
