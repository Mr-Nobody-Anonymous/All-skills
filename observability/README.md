# 📊 Local Observability & Telemetry Tracking (`observability/`)

100% local, privacy-preserving metrics and telemetry for skill routing, execution latency, and verification outcomes. Zero data leaves your machine.

```
observability/
├── routing/      # Selection accuracy, top-k win rates, and intent match logs
├── execution/    # Step durations, completion rates, and retry counts
├── tools/        # Tool invocation counts, latency profiling, and error rates
├── errors/       # Fingerprinted error traces, loop breaker hits, and rollbacks
├── performance/  # Token spend tracking, context window utilization
├── safety/       # Policy confirmation hits, sandbox boundary blocks
└── usage/        # Daily skill activation frequencies and user favorites
```
