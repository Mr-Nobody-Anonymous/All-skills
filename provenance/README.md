# 📜 Provenance & Software Bill of Materials (`provenance/`)

Tracks cryptographic digests, upstream Git commit hashes, license clearances, and third-party attribution notices for all skills in the platform.

```
provenance/
├── commits/   # Pinned upstream commit SHAs
├── hashes/    # SHA-256 package and file integrity hashes
├── licenses/  # Full-text open source licenses (MIT, Apache-2.0, BSD, CC0)
└── notices/   # Upstream contributor notices and copyright claims
```
