# 🥇 Advanced Engineering Projects

Complex, low-level, and distributed systems engineering projects inspired by [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x).

---

## 1. Build a Distributed Raft Key-Value Store (`raft-kv`)
- **Objective**: Implement the Raft consensus algorithm from scratch to create a fault-tolerant distributed key-value store.
- **Core Concepts**: Leader election, log replication, safety invariants, heartbeats, network partition recovery.
- **Tools**: Go, Rust, or C++.

## 2. Build a Programming Language & Bytecode VM (`custom-lang`)
- **Objective**: Create a complete scripting language with lexer, recursive-descent parser, AST generator, and bytecode virtual machine with garbage collection.
- **Core Concepts**: Lexical analysis, Pratt parsing, stack-based bytecode evaluation, Mark-and-Sweep GC.
- **Tools**: C, Rust, or Zig.

## 3. Build an x86 Monolithic Kernel (`mini-os`)
- **Objective**: Develop a 32-bit or 64-bit operating system kernel that boots via GRUB/QEMU.
- **Core Concepts**: Multiboot header, GDT/IDT setup, paging MMU, hardware interrupt drivers (keyboard, timer), simple shell.
- **Tools**: C, NASM Assembly, QEMU, GDB.
