# 🥉 Beginner Engineering Projects

Hands-on projects focused on mastering syntax, core algorithms, basic I/O, and clean code principles.

---

## 1. CLI Task & Habit Manager (`cli-task-tracker`)
- **Objective**: Build a terminal task manager using clean file storage (JSON/SQLite).
- **Core Concepts**: Command-line argument parsing, file persistence, CRUD operations, colorized terminal output.
- **Tools**: Python (`argparse` / `click`), Go (`cobra`), or Rust (`clap`).

## 2. HTTP Web Scraper & Markdown Extractor (`web-extractor`)
- **Objective**: Fetch remote HTML pages, parse DOM content, and output sanitized markdown notes.
- **Core Concepts**: HTTP requests, HTML parsing, CSS selectors, error handling, rate limiting.
- **Tools**: Python (`httpx`, `BeautifulSoup4`), Node.js (`cheerio`).

## 3. Real-Time Terminal Markdown Viewer (`md-term`)
- **Objective**: Render styled, syntax-highlighted markdown documents directly inside the terminal.
- **Core Concepts**: Terminal ANSI codes, syntax parsing, line wrapping, pager navigation.
- **Tools**: Python (`rich`), Go (`bubbletea`), Rust (`ratatui`).
