# Data Mesh Architecture

## Scope
Data mesh decentralizes analytical data management, shifting ownership from a centralized data team to cross-functional domain teams treating data as a product.

## Four Core Principles (Zhamak Dehghani)
1. **Domain-Oriented Decentralized Ownership**: Business domains (Billing, Logistics) own, clean, and serve their analytical datasets.
2. **Data as a Product**: Data products expose discoverable, addressable, trustworthy, and documented interfaces with explicit SLOs.
3. **Self-Serve Data Platform**: Common automated infrastructure enabling domain teams to build and deploy data products independently.
4. **Federated Computational Governance**: Standardized security, compliance, interoperability, and access control enforced automatically across the mesh.
