# Plumbing Trade & Code Compliance

## Scope
Plumbing systems design, potable water distribution, drain-waste-vent (DWV) piping, backflow prevention, and sanitary fixture installation under International Plumbing Code (IPC) and Uniform Plumbing Code (UPC).

## Core Formulations & Codes
- **Drainage Fixture Units (DFU) & Slope (IPC Chapter 7)**:
  - Minimum slope for horizontal drainage: $1/4\text{ in/ft}$ for pipes $\le 2\text{ in}$; $1/8\text{ in/ft}$ for pipes $3-6\text{ in}$.
- **Water Supply Fixture Units (WSFU, Hunter's Curve)**: Estimates peak instantaneous water demand for pipe sizing to prevent water hammer and pressure drops.
- **Trap Seal Protection & Venting**: Trap seal depth $2-4\text{ inches}$; Vent distance to fixture trap weir governed by pipe diameter (e.g., $1.5\text{ in}$ pipe $\implies$ max vent distance $6\text{ ft}$).
- **Backflow Prevention**: Reduced Pressure Zone (RPZ) assemblies and atmospheric vacuum breakers preventing cross-contamination.

## Standards & Tools
- **Standards**: International Plumbing Code (IPC), Uniform Plumbing Code (UPC), NSF/ANSI 61.
- **Tools**: Pipe Threader, ProPress hydraulic crimper, PEX expansion tool, Torch/flux/solder.
