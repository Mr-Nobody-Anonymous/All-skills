# Welding & Joining Technologies

## Scope
Thermal fusion joining of metals via arc welding processes, joint geometry, weld metallurgy (heat-affected zone), shielding gases, and non-destructive testing.

## Welding Processes & AWS Symbols
- **Processes**:
  - SMAW (Stick): Coated electrode; rugged, outdoor/field standard.
  - GMAW (MIG): Continuous wire feed with shielding gas ($Ar / CO_2$ mixtures).
  - GTAW (TIG): Non-consumable tungsten electrode, high precision for stainless steel, aluminum, and root passes.
  - FCAW (Flux-Cored): Tubular wire with internal flux; high deposition rate.
- **AWS A2.4 Weld Symbols**: Reference line, arrow, basic weld symbol (fillet, groove, plug), dimensions (throat, leg length), tail for process designation.
- **Quality & NDT**: Visual (VT), Dye Penetrant (PT), Magnetic Particle (MT), Ultrasonic (UT), and Radiographic (RT) testing per AWS D1.1 (Structural Welding Code - Steel).

## Standards & Tools
- **Standards**: AWS D1.1 (Steel), AWS D1.2 (Aluminum), ASME Boiler and Pressure Vessel Code Section IX.
