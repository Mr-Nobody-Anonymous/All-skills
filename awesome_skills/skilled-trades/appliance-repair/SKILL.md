# Appliance Repair & Diagnostics

## Scope
Field diagnostic testing, electrical schematic reading, error code retrieval, and mechanical/thermal servicing of residential appliances.

## Diagnostic Procedures
- **Electrical Testing**: Continuity testing across thermal fuses, heating elements ($R = V^2 / P$), bimetal thermostats, and solenoid water valves.
- **Motor Testing**: Inverter board three-phase winding resistance balance on direct-drive brushless motors ($<0.5\Omega$ variance across $U-V-W$).
- **Refrigeration Servicing**: Sealed system diagnostics using piercing valves, R600a (isobutane, flammable refrigerant) safety procedures.

## Standards & Tools
- **Tools**: Digital Multimeter, Clamp meter, Refrigerant recovery pump.
