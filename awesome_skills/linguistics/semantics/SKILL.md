# Formal Truth-Conditional and Model-Theoretic Semantics

## Overview & Core Principles
Formalize sentence meaning using typed lambda calculus, Montague semantics, generalized quantifiers, and intensional logic.

Compute denotations: $\llbracket \text{every boy sleeps} \rrbracket = \forall x (\text{boy}(x) \to \text{sleep}(x))$.
