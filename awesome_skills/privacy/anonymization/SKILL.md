# Statistical Data Anonymization and k-Anonymity

## Overview & Core Principles
Implement $k$-anonymity, $\ell$-diversity, and $t$-closeness on sensitive relational datasets to prevent re-identification.

Generalize quasi-identifiers (age, ZIP code) so that each equivalence class contains at least $k$ records.
