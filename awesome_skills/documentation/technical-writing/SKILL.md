# Technical Writing & Documentation Architecture

## Scope
Technical writing communicates complex architectural, engineering, and software concepts clearly, accurately, and concisely to developer and practitioner audiences.

## Core Principles & Documentation Types
- **The Diátaxis Framework**:
  1. *Tutorials*: Learning-oriented; guided lessons for beginners.
  2. *How-To Guides*: Task-oriented; step-by-step instructions to solve specific problems.
  3. *Reference*: Information-oriented; technical descriptions of APIs, syntax, and options.
  4. *Explanation*: Understanding-oriented; conceptual discussions and architectural rationale.
- **Style Guides**: Active voice, present tense, second person ("you"), concise sentences, adherence to Google Developer Documentation Style Guide or Microsoft Writing Style Guide.

## Tools & Standards
- **Platforms**: Diátaxis Framework, Vale (linter for prose), Markdown, AsciiDoc.
