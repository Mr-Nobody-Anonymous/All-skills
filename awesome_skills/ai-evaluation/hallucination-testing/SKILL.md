# Hallucination Testing & Factuality Verification

## Scope
Hallucination evaluation detects, quantifies, and mitigates unfaithful, non-grounded, or factually incorrect claims generated by generative AI systems.

## Verification Methodologies
- **RAG Triad Metrics (TruLens / Ragas)**:
  1. *Context Relevance*: Is the retrieved context relevant to the user query?
  2. *Groundedness (Faithfulness)*: Are all claims in the response strictly supported by the retrieved context?
  3. *Answer Relevance*: Does the generated answer address the original user query?
- **Self-Consistency & Entailment**: Natural Language Inference (NLI) classifiers verifying whether premises mathematically entail generated conclusions.

## Tools & Software
- **Software**: Ragas, TruLens, DeepEval, HaluEval benchmark.
