# Abstract Algebra

## Scope
Abstract algebra examines algebraic structures such as groups, rings, fields, modules, and vector spaces, exploring symmetry, algebraic invariants, and field extensions.

## Core Algebraic Structures
- **Group Theory**:
  - Definition: Set $G$ with binary operation satisfying closure, associativity, identity ($e$), and inverses ($g^{-1}$).
  - Lagrange's Theorem: If $H \le G$ is a subgroup of finite group $G$, then $|H|$ divides $|G|$.
  - First Isomorphism Theorem: $G / \ker(\phi) \cong \operatorname{im}(\phi)$.
  - Sylow Theorems: Guarantee the existence of $p$-subgroups in finite groups.
- **Ring & Field Theory**:
  - Ideal $I \triangleleft R$, quotient ring $R/I$.
  - Galois Theory: Connects field extensions $L/K$ to automorphism groups $\operatorname{Gal}(L/K)$, proving the insolvability of the quintic by radicals.
