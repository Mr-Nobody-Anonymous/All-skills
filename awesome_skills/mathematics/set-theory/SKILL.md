# Set Theory

## Scope
Set theory provides the axiomatic foundation for modern mathematics, formalizing sets, functions, relations, and transfinite numbers.

## ZFC Axiomatic Framework
- Axioms: Extensionality, Regularity (Foundation), Specification, Pairing, Union, Replacement, Infinity, Power Set, Axiom of Choice (AC).
- **Cardinality & Cantor's Theorem**: $|X| < |\mathcal{P}(X)|$; countable $\aleph_0$ vs. uncountable continuum $\mathfrak{c} = 2^{\aleph_0}$.
- **Transfinite Induction & Ordinals**: Well-ordered sets, von Neumann ordinals.

## Tools & References
- **Canonical References**: Jech — *Set Theory*; Kunen — *Set Theory: An Introduction to Independence Proofs*.
