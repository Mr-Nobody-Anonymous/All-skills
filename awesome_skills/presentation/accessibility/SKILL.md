# Accessible Presentation Design (WCAG 2.2 for Slides)

## Overview & Core Principles
Ensure slide deck color contrast compliance (4.5:1 ratio), screen-reader reading orders, and closed-captioning.

Never convey data trends solely through color (add direct chart labels and distinct line textures).
