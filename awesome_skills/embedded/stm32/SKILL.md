# STM32 Microcontroller Development

## Scope
Embedded firmware development across STMicroelectronics STM32 32-bit ARM Cortex microcontrollers using STM32Cube HAL, Low-Layer (LL) drivers, and direct register access.

## Peripheral & Driver Framework
- **Direct Memory Access (DMA)**: Circular and normal buffer DMA streams offloading CPU during ADC sampling, SPI/I2C transactions, and UART telemetry.
- **Timer Architectures**: Advanced control timers (TIM1/TIM8) with complementary outputs, dead-time insertion, and break inputs for motor drive.
- **STM32CubeMX / CubeIDE**: Clock tree configuration, pin muxing, automatic initialization code generation.

## Tools & Standards
- **Hardware**: ST-LINK/V2, V3, J-Link.
- **Software**: STM32CubeIDE, STM32CubeProgrammer, Segger Ozone.
