# Manufacturing Process Report Writer

## Purpose

Help draft structured manufacturing process reports, course project reports, process plans, and design documentation for mechanical engineering projects. The skill emphasizes traceable assumptions, process reasoning, inspection plans, and academic integrity.

Reports are drafts. A qualified engineer, instructor, or responsible reviewer must confirm technical correctness and submission requirements.

## When to Use

Use this skill when the user wants to:

- Write a manufacturing process report for a mechanical part or assembly.
- Document an FDM-based course project.
- Turn design notes into a structured report.
- Create sections such as abstract, design requirements, process route, parameters, inspection, risk analysis, and conclusion.
- Improve clarity without adding personal or fabricated information.

## Required Inputs

- Project title and objective.
- Part or assembly description.
- Material and manufacturing process.
- Design requirements and constraints.
- Available dimensions, parameters, and test results.
- Required report format, length, citation style, and language.
- Any course rubric that is allowed to share.

## Workflow

1. Confirm report type, audience, and allowed source material.
2. Build an outline before writing full text.
3. Separate known facts, assumptions, calculations, and recommendations.
4. Draft sections with neutral technical language.
5. Add manufacturing process route, equipment assumptions, inspection plan, and risk controls.
6. Flag missing data rather than inventing results.
7. Add final engineering and instructor-review reminder.

## Expected Outputs

- Report outline.
- Draft report sections.
- Tables for parameters, process route, inspection, and risks.
- Missing data list.
- Revision checklist.

## Acceptance Criteria

- The report contains no personal information, school IDs, or fabricated test data.
- Technical assumptions are visible.
- Manufacturing steps and inspection criteria are coherent.
- The text does not claim certified engineering approval.
- Final confirmation by a qualified engineer, instructor, or responsible reviewer is stated.

## Failure Handling

- If test data is missing, create placeholders and state that data must be measured.
- If the topic is too broad, propose a focused outline.
- If the user asks to hide authorship or fabricate sources, refuse and offer an ethical alternative.
- If the design is safety-critical, require formal engineering review and validation.

## Engineering Limitations

This skill cannot verify experimental results, certify manufacturing feasibility, or satisfy every instructor or institutional requirement. It cannot replace engineering review, lab testing, or academic integrity obligations. A qualified engineer, instructor, or responsible reviewer must confirm the final report.

## Example Invocations

- "Use `manufacturing-process-report-writer` to draft a PETG-FDM universal joint course project report."
- "Turn these FDM process notes into a manufacturing report outline."
- "Create an inspection and risk section for a 3D printed fixture report."
