# Incident Command System (ICS)

## Scope
The Incident Command System is a standardized, scalable management framework for emergency response. This skill covers ICS organizational structure, command and coordination functions, and operational planning.

## ICS Organizational Structure

### Command Staff
| Position | Role |
|----------|------|
| **Incident Commander (IC)** | Overall authority; sets objectives, strategy, priorities |
| **Public Information Officer (PIO)** | Media relations, public communications |
| **Safety Officer** | Monitors safety; authority to stop unsafe operations |
| **Liaison Officer** | Point of contact for assisting/cooperating agencies |

### General Staff (Sections)
| Section | Function | Key Activities |
|---------|----------|---------------|
| **Operations** | Tactical execution | Divisions, groups, branches; direct response activities |
| **Planning** | Situation assessment | Situation status, resource tracking, Incident Action Plan (IAP) |
| **Logistics** | Support and resources | Communications, food, medical, supplies, facilities |
| **Finance/Admin** | Cost tracking | Time recording, procurement, cost analysis, claims |

### Organizational Principles
- **Unity of command**: Each person reports to exactly one supervisor
- **Span of control**: 3-7 direct reports (optimal: 5)
- **Modular organization**: Expand/contract sections as needed
- **Management by objectives**: Clear, measurable incident objectives drive all actions

## Incident Action Planning Cycle
1. **Understand the situation**: Intelligence gathering, hazard assessment
2. **Establish incident objectives**: SMART objectives for the operational period
3. **Develop strategy/tactics**: How to achieve objectives
4. **Prepare the IAP**: Written plan including:
   - ICS 202 (Incident Objectives)
   - ICS 203 (Organization Assignment List)
   - ICS 204 (Assignment List — by division/group)
   - ICS 205 (Communications Plan)
   - ICS 206 (Medical Plan)
   - ICS 208 (Safety Message/Plan)
5. **Brief**: Planning meeting → operations briefing
6. **Execute**: Implement the plan
7. **Evaluate**: Track progress, adjust as needed

## Scaling ICS
- **Type 5** (local): Single resource, few personnel, IC handles all functions
- **Type 4**: Single resource with command and general staff positions
- **Type 3**: Extended attack; written IAP, division/group supervisors
- **Type 2**: Multi-branch operations, extended operational period
- **Type 1**: National-level complexity, full command/general staff

## Unified Command
- Multiple agencies with jurisdictional authority or functional responsibility
- Shared objectives, shared IAP
- Each agency maintains authority over its own resources
- Used for: multi-jurisdictional incidents, hazmat + fire + EMS, etc.

## ICS Forms Reference
| Form | Title | Purpose |
|------|-------|---------|
| ICS 201 | Incident Briefing | Initial response summary |
| ICS 202 | Incident Objectives | Goals for operational period |
| ICS 203 | Organization Assignment | Who fills what ICS roles |
| ICS 204 | Assignment List | Division/group tactical assignments |
| ICS 205 | Communications Plan | Radio frequencies, channels |
| ICS 206 | Medical Plan | Medical resources, hospitals |
| ICS 207 | Org Chart | Visual organization chart |
| ICS 209 | Incident Status Summary | Regular status report to higher authority |
| ICS 214 | Activity Log | Chronological record of events |
| ICS 215 | Operational Planning Worksheet | Tactical planning worksheet |

## Standards & Authority
- **NIMS (National Incident Management System)**: U.S. federal framework; ICS is a component
- **FEMA**: Training courses IS-100, IS-200, IS-700, IS-800 (free online)
- **Applicable in**: Wildfires, floods, hazmat, earthquakes, mass casualty, public health emergencies, planned events
