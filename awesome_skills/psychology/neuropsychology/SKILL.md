# Neuropsychological Assessment & Cognitive Rehabilitation

## Overview & Core Principles
Evaluate executive function, aphasia, amnesia, and focal brain injury impairments using standardized test batteries (WAIS, Halstead-Reitan).

Interpret standardized composite scores (Z-scores, T-scores, percentiles) reflecting frontal, temporal, and parietal deficits.
