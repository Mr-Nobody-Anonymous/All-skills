# Classical Test Theory (CTT) and Item Response Theory (IRT)

## Overview & Core Principles
Evaluate test reliability (Cronbach's alpha), construct validity, item difficulty parameters, and Rasch models.

Calculate test-retest and internal consistency reliability: $\alpha = \frac{K}{K-1} \left(1 - \frac{\sum \sigma_i^2}{\sigma_X^2}\right) \ge 0.80$.
