# Cognitive Psychology

## Scope
Cognitive psychology studies the internal mental processes that underlie human behavior: how people perceive, attend to, remember, think about, and make decisions about information.

## Core Domains

### Attention
- **Selective attention**: Focusing on one stimulus while filtering others
  - Broadbent's filter model: Early selection (physical features)
  - Treisman's attenuation model: Unattended stimuli are attenuated, not blocked
  - Late selection models: All stimuli processed to meaning level
- **Divided attention**: Performance on concurrent tasks; limited by resource capacity
- **Change blindness**: Failure to detect changes in visual scenes across interruptions
- **Inattentional blindness**: Failure to perceive visible objects when attention is directed elsewhere

### Perception
- **Bottom-up processing**: Data-driven, from sensory input to higher-level processing
- **Top-down processing**: Expectation-driven, knowledge guides perception
- **Gestalt principles**: Proximity, similarity, closure, continuity, figure-ground
- **Depth cues**: Binocular (stereopsis, convergence), monocular (perspective, occlusion, texture gradient)

### Memory Systems
| System | Duration | Capacity | Key Features |
|--------|----------|----------|-------------|
| Sensory | <1s (iconic), <4s (echoic) | Large | Pre-attentive |
| Working memory | ~20-30s without rehearsal | 7 ± 2 items (Miller) | Baddeley model: phonological loop, visuospatial sketchpad, central executive, episodic buffer |
| Long-term | Potentially unlimited | Unlimited | Declarative (semantic + episodic) vs. procedural |

- **Encoding**: Levels of processing (Craik & Lockhart) — deeper = better retention
- **Retrieval**: Recognition vs. recall; encoding specificity principle
- **Forgetting**: Decay, interference (proactive/retroactive), retrieval failure

### Reasoning & Decision-Making
- **Heuristics**: Availability, representativeness, anchoring (Tversky & Kahneman)
- **Dual process theory**: System 1 (fast, automatic) vs. System 2 (slow, deliberate)
- **Cognitive biases**: Confirmation bias, framing effect, sunk cost fallacy, hindsight bias
- **Problem-solving**: Means-ends analysis, analogy, insight

### Language Processing
- **Comprehension**: Syntactic parsing, semantic integration, pragmatic inference
- **Production**: Conceptualization → formulation → articulation
- **Bilingualism**: Executive function advantages, code-switching

## Research Methods
- **Reaction time paradigms**: Priming, Stroop, visual search
- **Eye tracking**: Fixation patterns reveal cognitive processing
- **EEG/ERP**: Temporal resolution of neural correlates
- **fMRI**: Spatial localization of cognitive processes
- **Behavioral experiments**: Accuracy, response time, signal detection theory (d', criterion)

## Applications
- **Human-computer interaction**: Cognitive load theory for UI design
- **Education**: Spaced practice, retrieval practice, interleaving
- **Clinical**: Cognitive-behavioral therapy (CBT) foundations
- **AI/ML**: Cognitive architectures (ACT-R, SOAR) inform AI agent design
