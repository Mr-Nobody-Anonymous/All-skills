## Operating Lifecycle Rules

1. **Physical Integrity**: All physical skills in `awesome_skills/` remain at their authoritative relative paths to prevent breaking existing URLs, harnesses, or external dependencies.
2. **Virtual Representation**: Any high-level re-indexing, super-domain mapping, task indexing, or maturity categorization is managed through `catalog/`.
3. **Single Source of Truth**: Global repository metrics are computed by `scripts/compute_stats.py` and stored authoritatively in `stats.json`. All markdown documentation and badges are synchronized directly from this file.
